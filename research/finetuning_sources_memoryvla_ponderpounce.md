## MemoryVLA

**Paper:** [arXiv:2508.19236](https://arxiv.org/abs/2508.19236), §§3–4, Appendix C. **Official implementation:** [OpenVLA branch](https://github.com/shihao1895/MemoryVLA/tree/openvla-codebase).

**Какие веса откуда / новые projection modules.** LIBERO shell загружает OpenVLA-7B Prismatic checkpoint (`research/sources/memoryvla-original/script/train/libero/train_libero_spatial.sh:3`). Код строго загружает Prismatic `projector`, `llm_backbone`, опционально `vision_backbone` (`vla/memory_vla.py:638-645`): это pretrained VLM weights, в том числе его штатный vision→LLM projector. Отдельно создаются новые MemoryVLA-модули: perceptual `per_compr=BottleneckSE(C_in=D_DINO+D_SigLIP, C_mid=2*256, C_out=256)` — `:402-410`; его архитектура — Conv1×1 reduce → SE excitation → Conv1×1 expand, новые параметры `:97-126`. Cognition — EOS hidden state LLM (ширина LLM, не отдельная learned projector), `:521-534`. `CogMemBank` и `PerMemBank` имеют каждый 2 retrieval `CrossTransformerBlock`: Q/K/V projections, residual LayerNorm, FFN 4×, затем gate `Linear(2D,D)`; temporal embedding тоже trainable (`:53-90,135-235,412-434`). Новый action expert — DiT-L (1024 hidden, 24 blocks, 16 heads), с noise-action `x_embedder: action_dim→1024`, cognition `z_embedder: LLM hidden→1024`, perceptual token `per_token_embedder:256→1024` и cross-attention в каждом block, output `1024→action_dim` (`action_model/models.py:14-18,181-245`; создание `vla/memory_vla.py:436-443`). В checkpoints VLM берётся из OpenVLA; PCMB/perceptual memory/DiT создаются с новой инициализацией, если не загружена MemoryVLA checkpoint. EMA diffusion копия заморожена (`memory_vla.py:448-451`). В авторском методе perceptual+cognition memory; базовый зрительный тракт DINOv2+SigLIP и LLaMA-7B.

**Реальный freeze stage, а не только defaults.** Скрипт не переопределяет freeze-flags: config `Exp_CogACT...` наследует `freeze_vision_backbone=False`, `freeze_llm_backbone=False` (`conf/vla.py:55-57,82-95`). `train.py:179-200` превращает именно их в `full-finetune` и вызывает `vla.freeze_backbones`; `prismatic.py:171-186` выставляет trainable vision backbone, LLM backbone и Prismatic projector. PCMB, оба memory bank и DiT также остаются trainable (`memory_vla.py:445-467`). Значит LIBERO recipe — full VLM + all new components, не projector-only. Код поддерживает и альтернативы: `align` замораживает оба backbone, обучает только projector; `finetune` замораживает vision, обучает LLM+projector (`prismatic.py:139-169`). Это доступные стадии, не обязательный авторский prereq; LoRA/rank/alpha/targets в просмотренных scripts/configs не обнаружены.

**Числа / кажущееся расхождение.** LIBERO Spatial script: 8 GPU × 32/device = global batch 256, LR 2e-5, 20k steps, `DiT-L`, repeated diffusion=4, `future_action_window_size=15` (`train_libero_spatial.sh:9-15,25-42`). Это ровно 16 action steps, так как forward берёт future window **плюс текущий action**: `actions[:, -(future_action_window_size+1):]` (`vla/memory_vla.py:548-550`). Следовательно, Appendix C global batch256/chunk16 не расходится со скриптом; 20k — конкретно этот LIBERO run, а не общий для датасетов лимит.

## PonderPounce

**Version-pinned paper:** [arXiv:2608.24115v2 HTML](https://arxiv.org/html/2608.24115v2), §§III-A–C, IV-A. Гиперпараметры сверены с v2, не с v1. Training/eval использует K=1; K=8 — исключительно latency profiling (§III-D).

В Qwen3.5-9B Ponder carrier embeddings случайные trainable параметры; carrier final hidden state — cognition ширины `H_Qwen`. Для π0.5 Pounce новая `cognition_proj: H_Qwen→H_PaliGemma`, `TimeTokenizer(H_PaliGemma)` — sinusoidal age in ms + trainable Linear(H,H), null cognition zero-init (`ponderpounce/model/s1_pi05.py:41-80`, `model/common.py:56-77`, `modeling.py:79-84`). Soft prefix `[age token, K projected cognition tokens]` передаётся в PaliGemma prefix (`s1_pi05.py:65-80,124-134`), который совместно обрабатывает язык/изображение; это не отдельный cross-attention memory reader. PI0.5 pretrained action expert/backbone загружается checkpoint-ом (`pi05/_vendored/pi05_pytorch.py:152-168`).

**Авторская оптимизация (paper v2).** RoboMME: AdamW, global batch32, clip1, warmup100 + constant **LR 2×10⁻⁵**, 4,320 episode-based steps; SigLIP frozen, PaliGemma LM + action expert trainable; flow/action:grounding weights 1:0.1; no cognition dropout; chunk20. RoboCasa-DC: 4,000 episode steps, LR1e-5, full fine-tune Ponder, explicitly no LoRA; action-only objective; 15% cognition dropout; chunk16 (§IV-A). Joint train, no separate bridge pretraining (§III-B). Grounding labels: teacher-forced transition, subgoal text, optional demo-reasoning; CE joins flow-matching MSE. Episode causal graph сохраняет градиент через весь earlier context **без temporal detach**; action gradients enter Ponder only via cognition and are scaled by 0.5; LM-head grounding gradients unscaled (§III-B). Multiple Pounce calls reuse cognition and accumulate its action gradients. Truncated/detached BPTT would be deviation, not faithful method.

Official [PonderPounce repository](https://github.com/worv-ai/PonderPounce), snapshot above, has inference/eval/model integration, no public training entrypoint. Поэтому числа и gradient flow выше — именно paper recipe, не утверждение о released trainer. RoboMME freezes SigLIP; RoboCasa full fine-tunes Ponder. Не обобщать один freeze policy на оба.

## Fetch: точные границы переноса

Пользовательская конфигурация: state12, action13 (arm7, gripper, body3, base_v, yaw), три камеры@10Hz. pi0.5 S1 adapter takes **32 padded** action/state slots: `action_in_proj=Linear(32,width)`, `action_out_proj=Linear(width,32)` (`pi05_pytorch.py:159-160`), wrapper zero-pads state to32 (`wrapper.py:97-108`). Поэтому 13D action **сам по себе не требует переинициализировать pretrained 32-wide action heads**: preserve them if coordinates fit expected slot layout and padding dimensions are masked in loss/decoding. Но Fetch смешивает absolute joint targets с base velocities; порядок, scaling, masks и target conventions должны быть explicitly mapped/validated. Если используемая модель/checkpoint и encoding несовместимы, менять лишь несовместимые adapter/head параметры, не делать blanket reset всех action weights. Новый bridge (carrier/cognition projection/age tokenizer/null) надо учить; Ponder base сохранять pretrained, freeze/PEFT — экспериментальный выбор, не paper recipe для RoboMME (там PaliGemma trainable) и не RoboCasa (там full fine-tune).

Для faithful Fetch SFT: синхронизировать три view на 10Hz; формировать causal episode sequences, cognition carrier K=1, action targets на Pounce ticks и cognition refresh/age на Ponder ticks; включать переходные/субцельные/демонстрационные текстовые targets только если доступны корректные labels. Сохранять граф на весь episode и повторно использовать cognition tensor, чтобы action loss из разных Pounce invocations агрегировался; не делать temporal detach. Применять flow-matching action loss, при наличии grounding — CE; множитель 0.5 только к action-derived градиенту в Ponder, не к grounding gradients. Это адаптация §III-B; требуются свои validation и Fetch-specific rates/loss masks.

**Нерешённое:** точное соответствие Fetch action13 Pi05 padded32 channels и mask/normalization в используемом checkpoint; корректная multi-camera data contract (три камеры не доказаны этой модельной конфигурацией); эффективные Fetch LR, refresh interval, LoRA/freeze и loss weights. Не утверждается, что released inference repo содержит обучающий код.
